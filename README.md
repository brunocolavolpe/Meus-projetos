⚡ DATA//FORGE

📊 Business Intelligence & Data Analytics

Projeto de estudos práticos desenvolvido para aprender Análise de Dados, Business Intelligence e Automação, partindo do zero até a construção de projetos profissionais para portfólio.

⸻

🎯 Objetivo

Desenvolver habilidades para atuar profissionalmente com dados, transformando informações brutas em insights, indicadores e decisões de negócio.

⸻

🧰 Tecnologias

* 📗 Excel
* 🔄 Power Query
* 🗄️ SQL
* 📊 Power BI
* 🧮 DAX
* 🐍 Python
* ⚙️ n8n
* 🐙 Git & GitHub

⸻

🗺️ Trilha de aprendizagem

01 — Excel

Fundamentos, fórmulas, funções, tabelas, gráficos e análise de dados.

02 — Power Query

Importação, limpeza, transformação e preparação de dados.

03 — SQL

Consultas, filtros, agregações, relacionamentos e análise de bancos de dados.

04 — Modelagem de Dados

Relacionamentos, tabelas fato e dimensão e estruturação de modelos.

05 — Power BI

Dashboards, indicadores, visualizações e análise de negócios.

06 — DAX

Medidas, cálculos, contexto de filtro e indicadores avançados.

07 — Python

Fundamentos de programação aplicados à análise e tratamento de dados.

08 — n8n

Automação de processos e integração entre ferramentas.

09 — Projeto Final

Construção de um projeto completo de dados, do problema de negócio até o dashboard final.
